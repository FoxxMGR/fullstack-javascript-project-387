# Фронтенд (web)

UI приложения «Календарь встреч», реализованный по API-контракту из `api-spec/`.

## Стек
- TypeScript + React + Vite
- Работа с API — только через контракт (`fetch`)

## Установка и запуск

```bash
npm install
npm run dev
```

Приложение запустится на `http://localhost:5173`.

## Настройка связи с бэкендом

Фронтенд обращается к контрактным путям `/guest/*` и `/admin/*`.
В dev-режиме Vite проксирует эти пути на отдельно запущенный бэкенд
по умолчанию на `http://localhost:8080` (см. `vite.config.ts`).

Если бэкенд работает на другом адресе/порту — измените `target` в `vite.config.ts`.

## Страницы
- **Гость** (`/guest`): просмотр типов событий → выбор свободного слота (окно 14 дней) → запись.
- **Владелец** (`/admin`): создание типов событий, список предстоящих/прошедших бронирований и их отмена.
